# Heap
- Priority queue를 구현하기 위해 사용되는 자료구조
- Stack : 가장 나중에 삽입된 data를 가장 먼제 삭제. Queue : 가장 먼저 삽입된 data를 가장 먼저 삭제
- Priority queue는 우선순위가 가장 높은 data를 가장 먼저 삭제
- 내부적으로 min heap and max heap 사용
- Min heap : 값이 낮은 data가 먼저 삭제. Max heap : 값이 높은 data가 먼저 삭제
- Min heap을 max heap처럼 사용하기 위해 -를 붙여서 저장할 수도 있음
