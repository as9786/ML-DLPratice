# 정렬
- Data를 특정한 기준에 따라서 순서대로 나열
- 이진 탐색을 가능하게 해줌
- 이진 탐색 전처리 과정

# 선택 정렬(Selection sort)
- 가장 작은 값을 선택해, 맨 앞과 바꾸고, 그 다음 작은 값을 선택해 앞에서 두 번째 값과 바꾸는 과정을 반복
- 원시적인 방법
- 시간 복잡도 : $O(N^2)$

# 삽입 정렬(Insertion sort)
- 선택 정렬보다 시간 효율적
- 특정한 값을 적절한 위치에 삽입
- 특정한 값이 적절한 위치에 들어가기 전에, 그 앞까지의 data는 이미 정렬되어 있다고 가정
- 시간 복잡도 : $O(N^2)$
- 정렬된 상태로 주어진 경우, 사용하면 효과적

# Quick sort
- 기준을 설정한 다음 큰 수와 작은 수를 교환한 후 list를 반으로 나누는 방식
- Pivot : 교환하기 위한 기준

## Hoare partition
- List에서 첫 번째 값을 pivot으로 정함
- 왼쪽에서 pivot보다 큰 값을 찾고, 오른쪽에서부터 pivot보다 작은 값을 찾음
