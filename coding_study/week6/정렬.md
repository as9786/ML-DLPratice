# 계수 정렬(Count sort)
- 특정한 조건이 부합될 때만 사용 가능
- Data range가 제한되어 정수 형태로 표현될 수 있을 때 사용 가능
- 시간 복잡도 : O(N+K)
- Ex) 성적 정렬
- 모든 범위를 담을 수 있는 list 생성
- 위 세 가지 방식처럼 직접 data value를 비교한 뒤에 위치를 변경하는 방식 X

## 공간복잡도
- Data가 0과 999,999만 있어도 list size가 100만개가 되도록 선언해야함
- 동일한 값을 여러 개 등장할 때, 효과적
