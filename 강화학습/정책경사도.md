# 정책 근사
- 가치 기반의 강화학습의 단점 : 행동 공간의 크기가 커지면 학습이 힘들어짐.
- By learning the policy directly from the data rather than deriving it from value functions, these limitations can be effectively overcome

# 정책 경사도 정리
- $max_{\theta} J(\theta)$
- 경사 상승법 : $\theta \leftarrow \theta + \alpha \nabla_{\theta} J(\theta)$
- 보상 최대화

## 수식
- $\nabla_{\theta} J(\theta) = E[\nabla_{\theta} log \pi_{\theta} (a|s) Q^{\pi} (s,a)]$
- $log \pi_{\theta} (a|s)$ : 선택한 행동의 확률을 얼마나 증가시켜야 하는가
- $Q^{\pi} (s,a)$ : 그 행동이 얼마나 좋았는가
- 좋은 행동 -> 확률 증가. 나쁜 행동 -> 확률 감소

# 기본적인 정책 경사도 강화학습
- Q를 모름 -> 전체 보상 활용
- $\nabla_{\theta} J(\theta) = E[\nabla_{\theta} log \pi_{\theta} (a|s)R]$
- 문제점 : 분산이 큼(최신화 방향이 계속 흔들림)
